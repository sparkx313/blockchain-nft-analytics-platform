# 🎨 NFT Analytics Platform

Advanced NFT market analytics with ML-powered price prediction.

## Features
- **Rarity Scoring** – trait-based rarity calculation
- **Wash Trade Detection** – identify artificial volume
- **Price Prediction** – LSTM model trained on sales history
- **Portfolio Tracker** – real-time P&L monitoring
- **Floor Price Alerts** – Telegram/Discord webhooks

## Rarity Algorithm
Uses a combination of:
1. Statistical rarity (trait frequency)
2. OpenRarity standard
3. Custom harmonic mean scoring
